# Publication scope

This repository contains only the material needed for the public B50
transition-geometry paper and its reproducibility audit.

The scientific object exposed here is the frozen B50 prime-gap transition-operator
analysis and its publication-generation lineage.

Excluded material includes unrelated internal research, unrelated exploratory
projects, personal working notes, and files not required to verify the paper's
reported claims.

A file is not considered publication-authoritative merely because it exists in a
working directory. Authority is established by the repository manifests, frozen
verdicts, and SHA-256 bindings.
