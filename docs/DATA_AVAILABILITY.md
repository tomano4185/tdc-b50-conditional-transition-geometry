# Data availability

## Included

The repository includes frozen derived machine outputs needed to audit the B50
publication result, together with machine-derived publication tables and figures.

## Raw corpus

The complete prime corpus is not redistributed through ordinary GitHub storage.
The source-provenance document states the segmentation contract required for an
independent reconstruction.

## Archival release

A DOI-bearing archival release may be added after the first public repository
freeze. The metadata builder intentionally allows the GitHub and archival URLs/DOI
to remain unset before that release exists.

When an archival DOI is minted, update `PUBLICATION_METADATA.json`, rerun
PublicGitHub-003, and freeze a new release tag.
